# Sushi LLVM-MinGW Windows x64 Toolchain

This package contains the complete LLVM-MinGW 20260616 UCRT x86_64 toolchain used by Sushi's `x86_64-w64-windows-gnu` native backend.

The package preserves the upstream directory tree without trimming compiler, linker, runtime, header, startup-object, library, or license files. It is Sushi's native dependency, not a general-purpose compiler distribution.

Upstream project: https://github.com/mstorsjo/llvm-mingw
